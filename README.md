# Health Assessment

Web-приложение для оценки состояния здоровья.

## Стек
- Backend: Java 21, Spring Boot 3.2, PostgreSQL
- Frontend: React 18, Vite, Bootstrap 5

## Структура
- `backend/` — серверная часть (Spring Boot)
- `frontend/` — клиентская часть (React SPA)
