# Health Assessment

Web-приложение для оценки состояния здоровья.

## Стек
- Backend: Java 21, Spring Boot 3.2, PostgreSQL / H2
- Frontend: React 18, Vite, Bootstrap 5

## Структура
- `backend/` — серверная часть
- `frontend/` — клиентская часть

## Сборка

### Backend
\`\`\`
cd backend
./gradlew build
\`\`\`

### Frontend
\`\`\`
cd frontend
npm install
npm run build
\`\`\`
